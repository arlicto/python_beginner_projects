# Small Python Projects

A collection of small Python projects built while learning programming.

| Project | Description |
|---------|-------------|
| [guess-the-number](./guess-the-number) | Number guessing game — player guesses a random number within limited attempts. |
| [higher-lower-game](./higher-lower-game) | Compare Instagram follower counts of two celebrities and guess who has more. |
| [love-calculator](./love-calculator) | Love compatibility calculator by counting letters in "TRUE" and "LOVE". |
| [blackjack](./blackjack) | Text-based Blackjack card game against a dealer. |
| [caesar-cipher](./caesar-cipher) | Caesar cipher encoder/decoder that shifts letters by a chosen amount. |
| [hist-painting](./hist_painting_project) | Turtle graphics dot painting — extracts colors from an image and paints rows of dots (Damien Hirst style). |
| [turtle_race](./turtle_race) | Turtle racing game — turtles move random distances; first across the finish line wins. |
| [snake-game](./snake_game) | Classic Snake Game built using Turtle graphics, featuring food consumption, collision detection, and score tracking. |
| [pong-game](./pong_game) | Two-player Pong game built with Turtle graphics — paddles, ball physics, scoring, and progressive speed. |
| [turtle-crossing-game](./turtle_crossing_game) | Turtle crossing game (Frogger-style) — navigate a turtle across a busy highway of moving cars. |

## Usage
