# Pong Game

A classic Pong game built using Python's Turtle graphics library. Two players control paddles to hit the ball back and forth. The ball speeds up with each hit, and the first player to miss loses the point.

## How to Play

- **Right paddle**: Up / Down arrow keys
- **Left paddle**: W / S keys
- The ball changes color on each paddle hit and gradually speeds up.

## Project Structure

- `main.py` — Game loop, collision detection, scoring
- `paddle.py` — Paddle class (movement, boundaries)
- `ball.py` — Ball class (movement, bouncing, speed, color)
- `scoreboard.py` — Scoreboard display class
