# Small Python Projects

A collection of small Python projects built while learning programming.

| Project | Description | Date Added |
|---------|-------------|------------|
| [turtle_race](./turtle_race) | Turtle racing game — turtles move random distances; first across the finish line wins. | 2026-06-08 |
| [diabetesPrediction](./diabetesPrediction) | ML model using scikit-learn to predict diabetes risk from a tabular dataset. | 2026-06-08 |
| [rock-vs-mine-prediction](./rock-vs-mine-prediction) | Logistic regression model that classifies sonar signals as rock or mine. | 2026-06-08 |
| [guess-the-number](./guess-the-number) | Number guessing game — player guesses a random number within limited attempts. | 2026-06-08 |
| [higher-lower-game](./higher-lower-game) | Compare Instagram follower counts of two celebrities and guess who has more. | 2026-06-08 |
| [love-calculator](./love-calculator) | Love compatibility calculator by counting letters in "TRUE" and "LOVE". | 2026-06-08 |
| [blackjack](./blackjack) | Text-based Blackjack card game against a dealer. | 2026-06-08 |
| [caesar-cipher](./caesar-cipher) | Caesar cipher encoder/decoder that shifts letters by a chosen amount. | 2026-06-08 |
| [hist-painting](./hist_painting_project) | Turtle graphics dot painting — extracts colors from an image and paints rows of dots (Damien Hirst style). | 2026-06-08 |
| [snake-game](./snake_game) | Classic Snake Game built using Turtle graphics, featuring food consumption, collision detection, and score tracking. | 2026-06-11 |
| [pong-game](./pong_game) | Two-player Pong game built with Turtle graphics — paddles, ball physics, scoring, and progressive speed. | 2026-06-11 |
| [turtle-crossing-game](./turtle_crossing_game) | Turtle crossing game (Frogger-style) — navigate a turtle across a busy highway of moving cars. | 2026-06-12 |
