# Small Python Projects

A collection of small Python projects built while learning programming.

| Project | Description |
|---------|-------------|
| [turtle_race](https://github.com/arlicto/turtle_race) | Turtle racing game — turtles move random distances; first across the finish line wins. |
| [diabetesPrediction](https://github.com/arlicto/diabetesPrediction) | ML model using scikit-learn to predict diabetes risk from a tabular dataset. |
| [rock-vs-mine-prediction](https://github.com/arlicto/rock-vs-mine-prediction) | Logistic regression model that classifies sonar signals as rock or mine. |
| [guess-the-number](https://github.com/arlicto/guess-the-number) | Number guessing game — player guesses a random number within limited attempts. |
| [higher-lower-game](https://github.com/arlicto/higher-lower-game) | Compare Instagram follower counts of two celebrities and guess who has more. |
| [love-calculator](https://github.com/arlicto/love-calculator) | Love compatibility calculator by counting letters in "TRUE" and "LOVE". |
| [blackjack](https://github.com/arlicto/blackjack) | Text-based Blackjack card game against a dealer. |
| [caesar-cipher](https://github.com/arlicto/caesar-cipher) | Caesar cipher encoder/decoder that shifts letters by a chosen amount. |

## Usage

Clone with submodules:

```bash
git clone --recursive https://github.com/arlicto/small_python_projects.git
```
